# Ollovin

Local AI assistant for Obsidian.

Ollovin adds a local AI layer over an Obsidian Vault: it indexes notes, retrieves relevant context, analyzes notes, and proposes safe changes for user review.

## MVP

The critical MVP focuses on:

- Ollama as the local LLM provider
- Manual Vault indexing
- Local embeddings and retrieval
- Hybrid search / RAG
- AI assistant sidebar
- Current-note analysis
- Suggestions for tags and wikilinks
- Structured, validated actions
- Review before applying changes
- Undo for the last AI operation

Destructive file deletion is intentionally not supported.

## Development

The project is an Obsidian desktop plugin written in TypeScript.
